# AI 가상 관중 발표 리뷰어 — Visual System

## Direction

Quiet editorial operating surface. The interface is a calm reading environment for a complex AI process: an open cool-gray canvas, black ink, one blue action color, hairline rules, and focused surfaces only where a task needs containment. It intentionally avoids dashboard density, decorative gradients, glow, and repeated metric cards.

## Core tokens

- Canvas: `surface #f5f5f7`, with `surface-container-low #f0f0f2` for quiet grouping.
- Content: `on-surface #161618`; supporting copy uses `on-surface-variant #68686f`.
- Action: `primary #1d4ed8`; primary container `#3b66ed`.
- Divider: `outline-variant #d1d1d6` at low opacity.
- Typography: local Pretendard variable font, system-like Korean sans with tight display tracking and relaxed body leading.
- Radius: 12px controls, 16px focused surfaces, full circles only for status/avatars.
- Elevation: hairline border first; no default shadow on page scaffolding.

## Composition

Home leads with one large action and demonstrates the product mechanism immediately: presentation → audience → discovery. Recording is a single centered stage. Analysis uses an open timeline and audience state. Results read as an editorial report: opening insight, map, audience reactions, evidence, transcript, and repair.

## Motion

Motion is used for state indication and preventing jarring changes. Entrances use opacity plus a 4px translate with the shared ease-out curve at 220ms. Listening bars reflect the real microphone/analyser state. Reduced-motion users receive opacity/color state changes without travel or looping motion.

## Accessibility

Every state has visible text, keyboard focus remains explicit, status changes use live regions, and color is never the only signal. Mobile reorders the report into insight → audience → map → evidence → transcript → improvement.
